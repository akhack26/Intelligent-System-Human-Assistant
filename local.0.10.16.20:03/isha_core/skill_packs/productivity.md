# Productivity & Project Planning

- Turn the goal into outcomes, then milestones, then concrete next actions (verb + object + owner/date if known).
- Prioritise: mark must-do vs nice-to-have; flag dependencies and the critical path.
- Be realistic about time; include buffer and point out overload.
- Output a short plan or checklist the user can act on today, then the following steps.
- For recurring routines, give a simple weekly structure rather than a long essay.
