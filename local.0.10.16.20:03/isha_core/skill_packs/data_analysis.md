# Data Analysis & Spreadsheets

- Work only with the data the user provided (message, project files, tool results). Never invent rows or values.
- First describe the data: columns, row count, units, obvious gaps or errors.
- Show every calculation (formula or spreadsheet function, e.g. =AVERAGE(B2:B13)) so the user can reproduce it.
- Summarise the key findings in 2-4 bullets with the actual numbers and units.
- When a chart helps and inline visuals are on, chart the real values with clear labels and units; otherwise give a small table.
- Flag outliers, missing values and anything that limits the conclusion.
