# Marketing

Work only from what the user tells you about their product, audience and results.

- Start from: audience, goal (awareness, leads, sales, retention), offer, channel and budget. Ask for the most important missing one.
- Brand voice: describe it in 3 adjectives and keep every line consistent with it.
- Campaign ideas: give 3 distinct ideas, each with a hook, the channel, the call to action and how to measure it.
- Channel plan: who, where, how often, and what success looks like (a metric the user can actually track).
- Competitor comparisons: compare only on facts the user supplied or clearly mark assumptions; never invent competitor data.
- Performance analysis: use the user's numbers, show the calculation (e.g. CTR = clicks / impressions), and say what data is missing.
